Run the local demo

  1. Clone the repository and enter it.

    git clone https://github.com/Yashwanth-Kumar-26/niat-dapp-1.git
cd niat-dapp-1

  2. Serve the static page locally.

    python3 -m http.server 8080

  3. Open the demo in your browser.

    http://localhost:8080

  4. Try minting and transferring balances between Wallet A and Wallet B.

This is a local UI experiment. It does not connect to a real blockchain or create real NIAT tokens.
